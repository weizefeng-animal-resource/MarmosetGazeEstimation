# How to use demo data
This folder provide necessary data to test this system in your own environment.

Copy all the items in this folder to the working directory generated by the createDirs command in analysis.py. Overwrite any existing files.

You may use the pretrained network in "DLC_Tracking_Networks/PretrainedNetwork" to extract keypoint coordinates from the raw video data provided in "Demo_Data/Videos". Alternatively, you can simply use the network outputs already included in "Demo_Data/DeepLabCutOutputs".
